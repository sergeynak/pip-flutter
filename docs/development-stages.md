# Этапы разработки макета

Здесь сохранены последовательные рабочие версии приложения. Чтобы посмотреть этап, откройте нужный коммит в истории репозитория.

| Этап | Коммит | Что добавлено |
| --- | --- | --- |
| 1 | 7f5af86 | Создать каркас Flutter-приложения |
| 2 | 61c0ffd | Сверстать главный экран и нижнее меню |
| 3 | 8a69e43 | Добавить каталог услуг и страницу услуги |
| 4 | 82db7cc | Добавить портфолио, поиск и галерею проекта |
| 5 | c262575 | Добавить блог и экран чтения статьи |
| 6 | e80cdd2 | Добавить форму заявки с проверкой полей |
| 7 | 8db26f6 | Добавить экран контактов и информацию о студии |
| 8 | Текущий этап | Добавить заготовку API, проверки и документацию |

Для каждого этапа выполнены форматирование, flutter analyze, проверка запуска и веб-сборка. На последнем этапе добавлены подробные тесты интерфейса.

На ранних этапах незавершённые разделы обозначены заглушками. Готовые экраны добавляются следующими коммитами. API пока не подключён: для него оставлен пустой файл с русским TODO.

Все коммиты созданы при подготовке этого репозитория; даты отражают время их создания.
