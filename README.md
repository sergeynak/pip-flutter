# Pip

Flutter-макет приложения студии Pip: экраны, переходы и локальные примеры данных. API не подключён. 

## Что работает

- Главная, услуги и подробные страницы.
- Портфолио с поиском по локальным проектам.
- Блог, чтение статей и примеры галереи.
- Контакты с неактивными демонстрационными адресами.
- Форма с проверкой обязательных полей и выбором услуг.
- Переходы, сообщение об ошибке, пустой результат и подтверждение закрытия заполненной формы.

Цены, тексты и иллюстрации — примеры. Кнопка формы сообщает, что заявка не отправлена; подтверждение успеха не имитируется. Введённые данные остаются только на открытом экране.

## Запуск

Используется Flutter **3.47.7** с Dart **3.13.5**.

```sh
flutter pub get
flutter run -d chrome
```
